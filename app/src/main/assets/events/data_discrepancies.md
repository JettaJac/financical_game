# Расхождения «Общее» / «ИВЕНТЫ»

- Обучение площадке: карточка `+20`, обучающий сценарий `-20`; в сценарии применяется `-20`.
- Кровать: карточка `-40`, сценарий `-50`; в сценарии применяется `-50`.
- Затопили: карточка `-40`, сценарий `-50`; в сценарии применяется `-50`.
- Парк: карточка `-40`, первый сценарный эпизод `-35`; второй остаётся `-40`.
- Гараж: карточка `+15`, сценарные действия дают `0`, `+20`, `+15`; override хранится в шагах сценария.
- Хендмейд: карточка `+30`, второй сценарный эпизод `+20`; оба требуют флаг `braidedBracelets`.
- Благотворительность указана как «50» без знака; трактуется как расход `-50`.
- Для выпечки, ягод и части офферов в исходных данных не заданы отдельные события открытия; они сохранены как `JobDef`/`jobActionId`, без выдуманного сюжетного оффера.
