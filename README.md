# Питомец Финни

«Питомец Финни» — офлайн-игра для знакомства детей с базовыми принципами финансовой грамотности. Пользователь создаёт виртуального питомца, планирует недельный бюджет, получает доходы, совершает покупки, выполняет задания и копит деньги на выбранные цели. Решения отражаются на балансе, характеристиках, комнате и развитии питомца.

Приложение не требует регистрации и подключения к интернету. Все игровые данные хранятся локально на устройстве.

## Реализованные функции

### Создание виртуального питомца

- стартовый онбординг и знакомство с Финни;
- выбор имени, цвета и типа шерсти;
- выбор первой финансовой цели;
- изменение имени и внешности в ходе игры;
- разные изображения питомца для уровней развития.

### Планирование бюджета

- обязательное планирование в начале каждой игровой недели;
- классификация операций как доходов или расходов;
- разделение операций на постоянные, нерегулярные, необязательные, непредвиденные и накопления;
- планирование суммы необязательных расходов;
- просмотр планового и фактического бюджета;
- подведение итогов недели и награда за соблюдение плана.

### Покупки и расходы

- покупка еды, развлечений, отдыха и предметов магазина;
- проверка достаточности денег перед покупкой;
- отображение стоимости и влияния действия на характеристики;
- скидка на следующую покупку как результат игрового события;
- учёт необязательных и непредвиденных расходов в фактическом бюджете.

### Накопления и финансовая цель

- выбор цели и отображение прогресса накопления;
- покупка цели после достижения требуемой суммы;
- постоянные бонусы за приобретённые цели;
- повышение уровня при покупке цели текущего уровня;
- обязательный выбор следующей цели после завершения предыдущей;
- вклады с разными сроками, ставками и штрафами за досрочное закрытие;
- учёт прибыли по вкладу как нерегулярного дохода и штрафа как убытка.

### Финансовые задания

- ежедневные дела и работы с вознаграждением;
- ограничения по дню недели, циклу, неделе и общему числу выполнений;
- расход энергии, здоровья и настроения при выполнении работ;
- открытие новых работ через события;
- блокировка повторного выполнения на время перезарядки;
- уборка комнаты с восстановлением чистого фона.

### Последствия и обратная связь

- события с положительными и отрицательными финансовыми последствиями;
- возможность принять или отклонить решение, если это разрешено сценарием;
- изменение денег, здоровья, счастья и энергии;
- визуальная реакция индикаторов на изменение значений;
- плавное снижение характеристик в течение цикла;
- постепенное загрязнение комнаты с каждым новым циклом;
- история действий с указанием цикла и изменения денег.

### Прогресс и развитие питомца

- уровни питомца и открытие нового контента;
- новые товары, действия и работы на последующих уровнях;
- постоянные модификаторы характеристик;
- сценарий событий по игровым дням и неделям;
- сохранение выполненных событий, покупок и ограничений заданий.

### Раздел для взрослого

- вход по паролю;
- просмотр истории действий ребёнка, сгруппированной по циклам;
- просмотр финансовых изменений;
- добавление собственной финансовой цели;
- очистка истории при полном рестарте игры.

### Сохранение состояния и демонстрационный режим

- восстановление профиля, денег, характеристик, цели, бюджета, событий, работ и таймера после перезапуска приложения;
- учёт времени, прошедшего при закрытом приложении;
- демонстрационный режим, позволяющий переключать циклы нажатием на кнопку цикла;
- сохранение состояния демонстрационного режима между запусками;
- отдельное включение и выключение режима через меню.

### Управление контентом

- события, сценарий и описания работ вынесены в JSON-файлы в `app/src/main/assets/events`;
- взрослый может добавить кастомную цель с названием и требуемой суммой;
- кастомная цель становится доступна в списке целей без изменения APK.

## Состав репозитория

```text
financial_game/
├── app/
│   ├── src/main/
│   │   ├── assets/
│   │   │   ├── events/       # события, работы и сценарий
│   │   │   └── webm/         # анимации онбординга
│   │   ├── java/ru/finni/financialpetgame/lct/
│   │   │   ├── data/         # GameStore, снимок состояния, каталог событий
│   │   │   ├── data/local/   # Room: сущности, DAO и база данных
│   │   │   ├── di/           # зависимости Hilt
│   │   │   ├── domain/       # экономика и игровые правила
│   │   │   └── ui/           # Compose-экраны и PetViewModel
│   │   ├── res/               # строки, изображения, иконки, темы и backup rules
│   │   └── AndroidManifest.xml
│   ├── src/test/              # локальные unit-тесты
│   ├── src/androidTest/       # инструментальные Android-тесты
│   ├── references/ui/         # визуальные референсы
│   └── build.gradle.kts       # конфигурация Android-модуля
├── gradle/libs.versions.toml  # версии библиотек и плагинов
├── gradle/wrapper/            # закреплённая версия Gradle
├── build.gradle.kts
├── settings.gradle.kts
└── gradlew / gradlew.bat
```

Архитектура приложения: `Compose UI → PetAction → PetViewModel → GameRepository/GameStore → GameSnapshot`. Приложение использует одну Activity; переходы между экранами и оверлеями управляются состоянием Compose без `NavHost`.

Основной стек: Kotlin, Jetpack Compose, Material 3, Coroutines/Flow, DataStore Preferences, Room, Hilt и KSP.

## Быстрый запуск

### Через Android Studio

1. Открыть корень репозитория в Android Studio.
2. Дождаться завершения Gradle Sync.
3. Установить Android SDK API 36, если IDE предложит это сделать.
4. Запустить эмулятор с Android 8.0 или новее либо подключить устройство с включённой USB-отладкой.
5. Выбрать конфигурацию `app` с параметром **Launch: Default Activity**.
6. Нажать **Run**.

Если после смены package name IDE пытается запустить `com.example.financial_game`, выполнить **File → Sync Project with Gradle Files** и пересоздать конфигурацию `app`.

### Из командной строки

macOS/Linux:

```bash
./gradlew :app:assembleDebug
./gradlew :app:installDebug
```

Windows:

```bat
gradlew.bat :app:assembleDebug
gradlew.bat :app:installDebug
```

Debug APK будет создан в:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Для запуска через ADB:

```bash
adb shell am start -n ru.finni.financialpetgame.lct/.ui.MainActivity
```

## Требования к окружению, версии инструментов и пошаговая инструкция по сборке APK-файла релизной версии

### Требования к окружению

| Инструмент | Требование проекта |
|---|---|
| Android Studio | актуальная стабильная версия с поддержкой AGP 9.2.1 |
| JDK | 17 или новее; проверенная локальная сборка использует JDK 17 |
| Gradle | 9.4.1, загружается через Gradle Wrapper |
| Android Gradle Plugin | 9.2.1 |
| Kotlin | 2.2.10 |
| Android SDK Platform | API 36 |
| minSdk / targetSdk | 26 / 36 |

Основные версии зависимостей закреплены в `gradle/libs.versions.toml`. Отдельно устанавливать системный Gradle не требуется — необходимо использовать `gradlew` из репозитория.

### Подготовка ключа подписи

Ключ подписи и пароли не должны храниться в Git. Для первой релизной сборки:

1. В Android Studio выбрать **Build → Generate Signed App Bundle or APK**.
2. Выбрать **APK** и нажать **Next**.
3. Нажать **Create new**.
4. Указать путь к файлу `.jks` вне репозитория.
5. Задать пароль хранилища, alias ключа, пароль ключа и срок действия.
6. Сохранить ключ и пароли в защищённом хранилище. Этот же ключ потребуется для всех обновлений приложения с package name `ru.finni.financialpetgame.lct`.

### Сборка подписанного release APK

1. Выполнить **File → Sync Project with Gradle Files**.
2. При необходимости проверить unit-тесты командой:

   ```bash
   ./gradlew testDebugUnitTest
   ```

3. Выбрать **Build → Generate Signed App Bundle or APK → APK**.
4. Выбрать созданный `.jks`, alias и ввести пароли.
5. Выбрать модуль `app`, вариант `release` и обе версии подписи — **V1** и **V2**.
6. Нажать **Create**.
7. Получить APK в каталоге:

   ```text
   app/release/
   ```

   Точный путь также показывается в уведомлении Android Studio после завершения сборки.

8. Проверить APK перед передачей:

   ```bash
   apksigner verify --verbose --print-certs app/release/app-release.apk
   adb install -r app/release/app-release.apk
   ```

Команда `./gradlew :app:assembleRelease` также собирает release-вариант, но без локально настроенного signing config полученный APK не считается готовым дистрибутивом. Для публикации следует использовать подписанную сборку из инструкции выше.

## Структура данных профиля, игровой экономики, заданий и прогресса

### Профиль питомца

| Группа | Данные |
|---|---|
| Идентичность | имя питомца |
| Внешность | цвет шерсти, тип шерсти, внутреннее поле цвета глаз для совместимости сохранений |
| Характеристики | здоровье, счастье, энергия, постоянные модификаторы и изменения текущего цикла |
| Состояние интерфейса | завершение онбординга и обучения главному экрану |

### Игровая экономика

| Группа | Данные |
|---|---|
| Баланс | текущее количество монет |
| Постоянный бюджет | регулярный доход и регулярные расходы |
| План недели | номер недели и сумма запланированных необязательных расходов |
| Факт недели | необязательные расходы и дополнительные/нерегулярные доходы |
| Вклад | сумма, цикл открытия, срок, процент и штраф за досрочное закрытие |
| Покупки | идентификаторы приобретённых товаров и целей |

### Задания и события

Задания содержат идентификатор, награду, влияние на характеристики, допустимые дни/циклы, лимит выполнений и связь с карточкой работы. События содержат вид события, денежные и статусные изменения, возможность отказа, частоту, минимальный уровень, флаги и открываемую работу.

Контент хранится в трёх файлах:

- `event_defs.json` — определения событий;
- `job_defs.json` — определения работ;
- `scenario_script.json` — порядок событий по неделям и дням.

В сохранение записываются счётчики выполнений, недельные лимиты, перезарядки, открытые работы, оставшееся количество действий, обработанные события и сценарные шаги.

### Прогресс

Сохраняются текущий цикл и срок его окончания, день и неделя, уровень питомца, выбранная цель, сумма цели, приобретённые цели и товары, загрязнение комнаты, флаги событий, история действий, кастомная цель и состояние демонстрационного режима.

Основное состояние хранится в DataStore Preferences (`game.preferences_pb`). В проекте также предусмотрена Room-база `financial_game.db` со структурой истории целей (`goal_records`: код и название цели, целевая и текущая суммы, время начала и завершения).

## Разрешения, собираемые данные и удаление профиля

### Обоснование разрешений

Приложение не объявляет пользовательских runtime-разрешений. Ему не требуются доступ к интернету, геолокации, контактам, камере, микрофону, файлам или уведомлениям.

В итоговом APK Android-библиотеки могут добавлять внутреннее permission с уровнем `signature` для безопасной работы компонентов внутри приложения. Оно не запрашивается у пользователя и не даёт доступ к данным устройства.

### Состав данных

Локально сохраняются:

- введённое имя питомца и выбранная внешность;
- баланс, бюджет, покупки, вклады и финансовые цели;
- здоровье, счастье и энергия;
- текущий цикл, таймер, уровень и загрязнение комнаты;
- выполненные задания, события и их ограничения;
- история игровых действий;
- кастомная цель, созданная во взрослом разделе;
- настройка демонстрационного режима.

Приложение не содержит аккаунтов, рекламы, аналитики, Firebase и сетевого API. Данные не отправляются разработчику или сторонним сервисам. Так как в манифесте разрешено стандартное резервное копирование Android, локальные данные могут попасть в системную резервную копию устройства, если пользователь включил её в настройках ОС.

### Удаление профиля

Есть два уровня удаления:

1. **Начать игру заново:** открыть меню, нажать **«Рестарт»** и подтвердить действие. Сбрасываются основной игровой профиль, деньги, бюджет, события, работы, перезарядки, история действий, вклад, обучение и демонстрационный режим.
2. **Полностью удалить все локальные данные:** открыть системные настройки Android → **Приложения → Питомец Финни → Хранилище → Очистить данные/хранилище**. Альтернативный способ — удалить приложение. Этот вариант удаляет DataStore, Room-базу и все остальные локальные данные приложения.

Для тестового устройства данные также можно удалить через ADB:

```bash
adb shell pm clear ru.finni.financialpetgame.lct
```

После полной очистки при следующем запуске откроется первоначальный онбординг.
